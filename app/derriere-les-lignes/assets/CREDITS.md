# Crédits des assets

`soldier.glb` : mannequin et animations de **Quaternius**, licence **CC0 1.0** (domaine public).

- Universal Animation Library (UAL1, Standard) : https://quaternius.com/packs/universalanimationlibrary.html
- Universal Animation Library 2 (UAL2, Standard) : https://quaternius.com/packs/universalanimationlibrary2.html

Clips retenus : Idle_Loop, Walk_Loop, Jog_Fwd_Loop, Sprint_Loop, Crouch_Idle_Loop, Crouch_Fwd_Loop, Death01, Hit_Chest, Pistol_Idle_Loop, Pistol_Aim_Neutral, Pistol_Shoot, Fixing_Kneeling, Sword_Attack, PickUp_Table (UAL1) ; Hit_Knockback, OverhandThrow, Walk_Carry_Loop (UAL2).

Converti et allégé avec `tools/build-soldier.mjs`. Les couleurs d'uniforme et l'équipement (casque, béret, sac, ceinturon, armes) sont générés dans `index.html`.

Soutenir l'auteur : https://www.patreon.com/quaternius
