Dossier 44-07 · Opération Brasier

Derrière les lignes

Un dépôt de carburant ravitaille toute la garnison. Infiltrez la base, posez l'explosif sur les cuves, puis rejoignez le camion au sud-est.

  • Toucher le sol : marcher. Double-toucher : courir (bruyant)
  • Couteau : touchez un garde pour l'approcher et le frapper par derrière, en silence. De face, il vous voit venir
  • Pistolet : touchez un garde pour tirer (bruyant). Un garde qui vous a repéré se vise directement, même couteau en main
  • Sniper : 3 balles. Vous vous allongez, la lunette s'ouvre, glissez pour viser. Il faut une ligne de tir dégagée
  • Corps : touchez-le (ou bouton Porter à côté) pour le charger sur l'épaule, puis Poser. L'anneau dessous dit s'il est caché : vert à l'abri, orange exposé, rouge dans un cône
  • Glisser : déplacer la vue. Pincer : zoomer
  • Cône foncé : on vous voit même en rampant. Cône clair : seulement debout
